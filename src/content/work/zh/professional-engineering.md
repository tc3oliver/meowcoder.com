從 2017 年開始投入 AI 應用，之後隨著工程職責擴大，工作範圍也延伸到系統整合、架構設計與企業 AI 系統。

## 應用程式工程

<p class="stage-metadata">Mobile · Web · Connected Products</p>

早期以行動與 Web 應用開發為主，也參與連網產品的使用者體驗與功能實作。

這個階段建立了端到端交付：從前端做到後端，再擴展到 API 與雲端整合。

<p class="stage-domains"><span>代表性系統</span> 行動與 Web 應用 · 智慧家庭 · 連網產品</p>

## 企業系統與系統架構

<p class="stage-metadata">Cloud · Integration · Security · DevOps</p>

之後工作範圍擴展至企業系統與平台架構，包括後端服務、雲端環境、系統整合、
身分與權限、軟體交付與正式環境維運。

工作重心也從單一應用，轉向整體系統的設計與交付。

這個階段也持續把 AI 能力加進產品與企業流程，同時承擔更多系統架構與
技術領導責任。

<p class="stage-domains"><span>代表性系統</span> 企業流程 · 公部門系統 · 醫療平台 · 雲端 / 資安 / CI/CD</p>

**技術領導** — 負責架構決策、工程規範、CI/CD 與品質流程、專案交付，
以及技術指導與經驗傳承。

## 企業 AI 系統

<p class="stage-metadata">Agent · Knowledge · Conversational AI · LLM</p>

近年的工作重心轉到企業 AI 系統，包括 coding agent、知識檢索、
LLM 基礎架構與模型服務，把模型能力放進實際產品與開發流程。

工程範圍不只是模型本身，也包括驗證、權限控管、可觀測性、並行處理，
以及實際的使用者工作流程。

<p class="stage-domains"><span>代表性系統</span> 對話式 AI · 會議智慧 · 自然語言資料查詢 · 隱私導向電腦視覺 · coding agent · 知識系統 · LLM 基礎架構</p>
